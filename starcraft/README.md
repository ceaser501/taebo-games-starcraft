# StarCraft

브루드워 1:1 (브라우저). 개발 서버에서는 `/starcraft/`로 열립니다.

## 원본 데이터

스타크래프트 리마스터 설치 폴더(`Data/` CASC 저장소)에서 필요한 파일만 꺼내 비공개 저장소
`ceaser501/taebo-games-starcraft-assets`에 둡니다. CascView는 Windows 전용이라 Node 도구를 씁니다.

```bash
node starcraft/tools/casc.mjs list "$SC" > casc-list.txt          # 파일 목록과 크기
node starcraft/tools/casc.mjs extract "$SC" ~/sc-assets 'arr/' 'scripts/' ...   # 꺼내기 (* 와 ! 지원)
```

`npm run sc:pack -- <assets 경로>`가 그 데이터를 `starcraft/assets/sc/`(git에 안 올림)로 바꿉니다.

| 결과 | 내용 |
|---|---|
| `data/core.bin.gz` + `.idx` | 유닛·무기 표, 애니메이션 스크립트, 유닛 그림(GRP), 지형 속성 |
| `data/<타일셋>.bin.gz` + `.idx` | 타일셋 그림, 팔레트, 조명표 (맵의 타일셋만 받음) |
| `sound/**.wav` | 효과음·음성 (원작 22kHz, 처음 재생할 때 받음) |
| `maps/**` + `maps.json` | 맵 (.scm/.scx 그대로) |
| `portrait/**.webm` | 초상화 (리마스터 SD의 WebM, 대기·말하기 클립) |
| `ui/*.png` + `ui.json` | 원작 화면 그림: 콘솔, 와이어프레임, 버튼 틀, 자원 아이콘, 커서(리마스터 SD의 DDS를 PNG로), 비트맵 글꼴(.fnt), 유닛 이름(stat_txt.tbl) |

## 엔진

`engine/`의 OpenBW(헤더만, `engine/openbw/VENDORED.md`에 고친 점)와 `engine/game.cpp`(페이지와 잇는 C 함수)를
Emscripten으로 `js/engine/bw.mjs` + `bw.wasm`으로 빌드합니다. 빌드 결과는 저장소에 들어 있어서,
엔진을 고칠 때만 Emscripten이 필요합니다(`npm run sc:engine`).

- 게임 계산은 원작과 같습니다(정수 계산, 원작 난수). 그래서 같은 명령을 같은 프레임에 넣으면 두 컴퓨터의 결과가 같습니다.
- 그림은 원작 SD 그래픽을 8비트 팔레트 그대로 그립니다. 안개는 타일 사이를 부드럽게 섞습니다.
- `engine/build-test.sh`는 같은 코드를 네이티브로 빌드한 시험 프로그램(`test.cpp`)입니다. 스크린샷과 상태 해시를 냅니다.

## 온라인 대전

메뉴의 **친구와 온라인 대전**에서 이름을 적고, 한 명이 **방 만들기**를 누르면 대기실이 열립니다.
친구가 5자리 방 코드로 **참가**하면 대기실에 이름이 뜨고(알림음), 방장이 맵을 골라 **게임 시작**을 누릅니다.
로그인은 없습니다. 판이 끝나면 방장이 **대기실로**를 눌러 다시 할 수 있습니다.

- 메시지는 Worms와 같은 Supabase Realtime 채널(프로젝트 `gxyckkinlygeasruapmj`, 채널 이름 `tbsc-<코드>`)로 중계됩니다.
  테이블은 쓰지 않고 broadcast와 presence만 씁니다. `js/net.js`는 Worms의 것을 그대로 가져왔습니다.
- **락스텝** (`js/lockstep.js`): 명령만 주고받습니다. 2프레임(84ms)이 한 턴이고, 턴 k에 내린 명령은 턴 k+4(약 0.34초 뒤)에
  양쪽에서 같은 순서로 실행됩니다. 상대 명령이 아직 안 왔으면 그 턴에서 기다립니다(화면 왼쪽 위 "상대를 기다리는 중").
  패킷마다 바로 앞 턴 명령을 한 번 더 실어 보내고, 그래도 빠지면 다시 보내 달라고 요청합니다.
- **체크섬**: 48프레임(2초)마다 양쪽이 게임 상태 해시를 보내 비교합니다. 다르면 화면 위에 알립니다.
- **연결 끊김**: 상대가 사라지면 1분까지 기다립니다(게임은 멈춤). 돌아오면 빠진 턴을 다시 받아 이어 갑니다.
  1분이 지나거나 상대가 **항복하고 나가기**를 누르면 남은 사람이 이깁니다.
- 1초에 양쪽 합쳐 약 24개 메시지입니다. 10분 한 판에 약 1만 5천 개로, Supabase 무료 한도(월 200만 개) 안입니다.
- 탭을 다른 데로 돌리면 브라우저가 그 탭을 멈춰서 상대도 기다리게 됩니다.

## 화면

원작처럼 640x480 화면 하나를 그리고, 창 크기에 맞춰 4:3 비율로 늘립니다(양옆 검은 띠).
지도 위에 종족별 콘솔 그림을 얹고, 미니맵(128x128), 상태창(와이어프레임, 이름, 체력, 생산 대기열과 진행 막대),
명령 카드(버튼 틀 위 아이콘, 누르면 1픽셀 밀림, 올리면 밝아짐, 위에 설명), 오른쪽 위 자원, 왼쪽 아래 메시지를
모두 원작 그림과 비트맵 글꼴로 그립니다. 글자는 원작과 같은 영어입니다. 커서도 원작 것(화살표, 아군·적·중립 돋보기,
조준, 화면 끝 스크롤)입니다.

## 테란 (3단계)

테란 유닛·건물의 원작 명령 카드가 모두 들어 있습니다: SCV 기본·고급 건물, 생산, 애드온, 연구·업그레이드,
집결지, 건물 띄우기·내리기, 스팀팩, 시즈 모드, 클로킹, 마법(락다운, EMP, 이레디에이트, 디펜시브 매트릭스,
야마토, 스캐너, 힐, 리스토레이션, 옵티컬 플레어, 스파이더 마인, 핵), 벙커·드랍십 태우기와 내리기.
버튼이 켜지는지는 엔진의 원작 판정(`unit_can_build`, `unit_can_research`, `unit_can_use_tech` 등)을 그대로 씁니다.
상태창에는 연구·업그레이드·애드온 진행, 탑승 유닛(누르면 내림), 처치 수, 에너지, 방어·무기 업그레이드 아이콘이 나옵니다.

## 프로토스·저그 (4단계)

메뉴에서 내 종족(테란·프로토스·저그·랜덤)을 고릅니다. 혼자 테스트는 상대 종족도 고르고, 온라인은 대기실에서 각자
고르며 랜덤은 방장이 시작할 때 정해서 양쪽에 보냅니다.

- 프로토스: 프로브 워프 건설(파일런 전력 범위 안에만, 배치할 때 파일런 범위 표시), 전력 없는 건물은 Disabled,
  게이트웨이·로보틱스·스타게이트 생산, 포지·사이버네틱스 코어 등 모든 연구·업그레이드, 실드 표시(상태창 숫자와
  실드 업그레이드 아이콘), 사이오닉 스톰·할루시네이션·리콜·스테이시스·디스럽션 웹·마인드 컨트롤·피드백·마엘스트롬,
  하이 템플러 둘 이상으로 아콘, 다크 템플러로 다크 아콘, 캐리어 인터셉터·리버 스캐럽 생산(개수 표시), 셔틀 태우기.
- 저그: 해처리 선택 후 **S**로 라바 선택, 라바 변태(여러 마리 선택하면 모두), 알·고치 취소, 드론이 건물로 변태
  (크립 위에만), 해처리→레어→하이브, 스파이어→그레이터 스파이어, 크립 콜로니→성큰·스포어, 히드라→러커,
  뮤탈→가디언·디바우러, 버로우(드론·저글링·히드라·디파일러·인페스티드 테란·러커), 퀸·디파일러 마법, 나이더스 출구,
  오버로드 태우기(벤트럴 색).
- 종족별 원작 조언자 음성(자원 부족, "Spawn more Overlords", "Construct additional Pylons", 연구·업그레이드 완료,
  공격받음), 건물 배치 소리, 콘솔 그림.

혼자 테스트에서는 **F9**로 원작 치트(show me the money + operation cwal: 미네랄·가스 10000, 빠른 건설)를 켭니다.
온라인 대전에서는 동작하지 않습니다. 주소에 `?debug`를 붙이면 개발자 도구에서 `window.sc`로 엔진에 접근할 수 있습니다.

## 원작 알림

자원·보급·에너지가 모자라거나 지을 수 없는 곳이면 원작 문구와 조언자 음성이 나옵니다. 유닛 생산 완료 음성,
SCV의 건설 완료, 연구·업그레이드·애드온 완료, 핵 준비·핵 발사 감지, 기지·병력 공격받음(미니맵 깜빡임)도 원작대로입니다.
버튼 설명과 단축키는 원작 `stat_txt.tbl`의 글자를 색 코드까지 그대로 씁니다. 게임 메뉴와 승리·패배 창도
콘솔의 원작 대화상자 그림으로 그립니다.

## 조작

| 입력 | 동작 |
|---|---|
| 왼쪽 클릭 / 드래그 | 선택 (Shift 추가·빼기, 더블클릭·Ctrl 화면 안 같은 유닛 전부) |
| 오른쪽 클릭 | 이동·공격·채취·수리 (Shift 예약) |
| 방향키, 미니맵 클릭·드래그 | 화면 이동 (전체화면에서는 화면 끝으로도) |
| 미니맵 오른쪽 클릭 | 그곳으로 명령 |
| Ctrl+숫자 / 숫자 / Shift+숫자 | 부대 지정 / 부르기 (두 번 누르면 화면 이동) / 추가 |
| 명령 단축키 | 원작과 같음 (M 이동, S 정지, A 공격, P 정찰, H 위치 사수, G 채취, C 반납, B 건설) |
| Esc | 명령·건설 취소, 생산 취소 |
| F10 / Esc | 게임 메뉴 (혼자 테스트에서는 일시정지 가능) |
| F2~F4, Shift+F2~F4 | 저장한 화면으로 이동 / 지금 화면 저장 |
| Enter | 채팅 (혼자 테스트에서는 show me the money, operation cwal 치트) |
| Alt+미니맵 클릭 | 핑 (상대 화면에도 깜빡임) |
| F9 | 치트 (혼자 테스트만): 미네랄·가스 10000, 빠른 건설 |

## 구조

|---|---|
| `js/app.js` | 비밀번호 화면, 메뉴, 게임 시작 |

| `js/net.js` | Supabase Realtime 방·대기실 연결 (Worms와 같음) |
| `js/console-ui.js` | 콘솔·미니맵·상태창·명령 카드·자원·글자·커서 그리기 |
| `js/units.js` | 세 종족 명령 카드(버튼 위치·단축키·아이콘·설명), 종족별 원작 안내 문구 |

| `js/sound.js` | 효과음·음성 재생 (Web Audio, 동시 8개) |
| `engine/game.cpp` | 엔진 쪽 함수: 시작, 프레임, 명령, 그리기, 안개, 미니맵, 선택 |
| `engine/platform.cpp` | SDL 대신 메모리 화면 |
| `tools/casc.mjs` | 리마스터 CASC 저장소 읽기 |
| `tools/pack-data.mjs` | 데이터 묶기 |
| `tools/image-formats.mjs` | DDS(DXT1/5), .dds.grp, .fnt 글꼴, PCX 읽기, PNG 쓰기 |
